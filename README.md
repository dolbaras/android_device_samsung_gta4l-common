# Common device tree — Galaxy Tab A7 10.4 (SM-T505 / SM-T500)

**[Русский](#русский) · [English](#english)** · Сборка / build: [LineageOS 18.1](https://github.com/dolbaras/gta4l-los18.1) · [PixelExperience Plus](https://github.com/dolbaras/gta4l-pe-plus) · Прошивки / ROMs: [gta4l-gta4lwifi-roms](https://github.com/dolbaras/gta4l-gta4lwifi-roms)

## Русский

Общее дерево Galaxy Tab A7 10.4 (**SM-T505** и **SM-T500**) для Android 11: настройка платформы SM6115, SELinux, звук с Dolby Atmos и четырьмя динамиками, init-скрипты. Одна ветка `lineage-18.1` собирает и LineageOS 18.1, и PixelExperience Plus.

Файлы Dolby Atmos в `dolby/` принадлежат Dolby Laboratories, см. [PROPRIETARY_NOTICE](dolby/PROPRIETARY_NOTICE.md).

---

## English

Common tree of the Galaxy Tab A7 10.4 (**SM-T505** and **SM-T500**) for Android 11: SM6115 platform setup, SELinux, audio with Dolby Atmos and four speakers, init scripts. The single `lineage-18.1` branch builds both LineageOS 18.1 and PixelExperience Plus.

The Dolby Atmos files in `dolby/` belong to Dolby Laboratories, see [PROPRIETARY_NOTICE](dolby/PROPRIETARY_NOTICE.md).
